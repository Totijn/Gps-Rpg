## 📱 How to put the game on your Phone!

Want to take the game outside? It's like magic!

1.  Open the game on your computer.
2.  Look for the **Mobile Link** in the starting window (it looks like `http://192.168.1.5:3001`).
3.  Type that link into the web browser on your phone.
4.  **Important:** Look for the button that says **"📱 Install"** or **"Add to Home Screen"** inside the game.
5.  Click it, and **BOOM!** The game is now an app on your phone with its own icon! 🎈

## 🛠️ For Developers (How to run from Source)

If you want to run the code yourself:

1.  **Install Bun:** Go to [bun.sh](https://bun.sh) and follow the instructions.
2.  **Download Code:** `git clone` this repository.
3.  **Launch:**
    -   **Windows:** Double-click `play.bat`
    -   **Mac/Linux:** Run `./play.sh` in your terminal.

---

## 🛠️ How to update the App (For Developers)

If you are the owner and want to make a new download file for everyone:

1.  Make sure you have finished your changes.
2.  Double-click `release.bat`.
3.  Type a version name like `v1.0.0` and press Enter.
4.  Wait a few minutes! GitHub will build the new app and put it in the **Releases** section for you! 🚀

## 🎮 What can you do in this game?
-   **Be a Hero:** Pick from a strong **Warrior**, a powerful **Mage**, or a fast **Archer**!
-   **Level Up:** The more you walk outside, the stronger you get!
-   **Find Monsters:** Battle pixel monsters that appear on your map.
-   **Boss Raids:** Every 5 minutes, a giant Boss appears. Ask your friends to join your party to beat it together! ⚔️
-   **Chat:** Talk to other players in the game world!

## 🎒 Tips for Parents
-   This game uses GPS to show the player on a map.
-   It works best when walking outdoors!
-   No personal data is shared; it's all about pixel-art fun.

Have fun adventuring! 🌟
