# 🌍 Pixel GPS MMORPG

Welcome, Adventurer! This is a real-life game where you become a hero by walking around outside! 🚶‍♂️✨

## 🚀 How to Play (The Easy Way!)

If you want to start right now, just do this:

### 🪟 If you have a Windows Computer:
1. Find the file named `play.bat`.
2. **Double-click it!**
3. Wait for the green text to appear. It will start the game for you!

### 🍎 If you have a Mac or Linux:
1. Open your terminal.
2. Type `./play.sh` and press Enter.

---

## 📱 How to put the game on your Phone!

Want to take the game outside? It's like magic!

1. Start the game on your computer using the steps above.
2. Look at the black window (the terminal). It will show a "Mobile Link" that looks like `http://192.168.1.5:3001`.
3. Type that link into the web browser on your phone.
4. **Important:** Look for the button that says **"📱 Install"** or **"Add to Home Screen"**.
5. Click it, and **BOOM!** The game is now an app on your phone with its own icon! 🎈

---

## 💻 How to make a real App (.exe) for your PC!

If you want a real icon on your computer that you can click anytime, do this:

1. Open your terminal or command prompt in this folder.
2. Type this: `bun run dist:win`
3. Wait for it to finish.
4. Go into the folder named `dist`.
5. You will find a file that says **GPS MMORPG Setup**. Double-click it to install the game just like Minecraft or Roblox! 🎮

---

## 🎮 What can you do in this game?
- **Be a Hero:** Pick from a strong **Warrior**, a powerful **Mage**, or a fast **Archer**!
- **Level Up:** The more you walk outside, the stronger you get!
- **Find Monsters:** Battle pixel monsters that appear on your map.
- **Boss Raids:** Every 5 minutes, a giant Boss appears. Ask your friends to join your party to beat it together! ⚔️
- **Chat:** Talk to other players in the game world!

## 🎒 Tips for Parents
- This game uses GPS to show the player on a map.
- It works best when walking outdoors!
- No personal data is shared; it's all about pixel-art fun.

Have fun adventuring! 🌟
